# Проекты для дипломной работы

Данный репозиторий содержит два веб-проекта, разработанных в рамках
подготовки и выполнения дипломной работы.  
Проекты демонстрируют практические навыки frontend и backend разработки,
а также работу с клиент-серверной архитектурой и внешними сервисами.

Каждый проект расположен в отдельной директории и имеет собственную
документацию с описанием функциональности и инструкцией по запуску.

## Список проектов

### 🌦 Проект «Прогноз погоды по городу»

Статичный веб‑сайт для просмотра актуальной погоды по названию города.
Работает полностью в браузере и использует внешний погодный API.

📄 **Документация проекта:**

### 📝 Проект «Todo List»

Веб‑приложение для управления списком задач с серверной логикой.
Реализовано на Node.js с использованием Express и MongoDB.
