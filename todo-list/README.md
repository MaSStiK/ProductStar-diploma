# Todo List

Веб-приложение **Todo List** для управления списком задач.
Проект реализован на Node.js с использованием Express и MongoDB.
Поддерживает создание, просмотр, обновление и удаление задач.

## Возможности

- Добавление новых задач
- Просмотр списка задач
- Отметка задач как выполненных
- Редактирование задач
- Удаление задач
- Хранение данных в MongoDB

## Используемые технологии

- HTML5
- CSS3
- Node.js
- Express
- MongoDB
- Mongoose
- EJS (шаблонизатор)
- body-parser
- method-override

## Требования

- Node.js (v16+ рекомендуется)
- MongoDB (локально или через Docker)

## Установка и запуск

### 1. Скачайте или клонируйте проект

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск сервера

```bash
node app.js
```

### 4. Открытие в браузере

```
http://localhost:3000
```

## Маршруты приложения

- `/` — главная страница
- `/todos` — список задач и управление ими

## Примечания

- Все запросы выполняются из браузера
- Все данные сохраняются в MongoDB
- Проект предназначен для учебных и демонстрационных целей
